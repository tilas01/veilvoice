TWO THINGS THIS LICENCE IS NOT, SAID PLAINLY
--------------------------------------------

1. IT IS NOT AN OPEN SOURCE LICENCE.

   "Open source" and "free software" both mean, among other things, that you
   may use the work for any purpose including a commercial one. The
   NonCommercial term above means VeilVoice does not meet either definition.

   The accurate word is SOURCE-AVAILABLE. Everything about this project that
   made it checkable is unchanged - the source is public, the builds are
   reproducible, the artwork and documentation are generated by scripts you
   can run yourself, and there is no unsafe code and no network code. What
   changed is the freedom to sell it, which is now reserved.

   This project used to call itself libre. It does not any more, because that
   would now be untrue, and the point of this document is that it is not.

WHY THIS LICENCE
----------------

The author wants the work read, checked, forked and built on, and does not want
somebody else selling it. CC BY-NC-SA says exactly that.

There is a real cost and it is recorded rather than hidden: most Linux
distributions will not carry NonCommercial software in their main
repositories, and Creative Commons itself advises against using CC licences for
software, on the ground that they do not carry the source-code and
distribution terms a software licence usually would. Both were known when this
was chosen.


THE DEPENDENCIES

Every third-party library VeilVoice uses is under its own permissive licence -

change any of them; that code stays under its own terms, including its own
attribution requirements.

One consequence worth knowing: this licence cannot be combined with GPL code in
either direction. Audacity is recommended and integrated with, and its source
is never copied in. That was already the rule under the GPL, for a different
reason, and it still is.
