Render a recording according to a plan.

Writes the audio and both subtitle formats. Audio that no turn claims is **silenced**, never passed through -- it has not been veiled, and a gap in a plan must not put a real voice into the result. How much went is printed.

Usage: veilvoice conversation render [OPTIONS] <PLAN> <INPUT>

Arguments:
  <PLAN>
          The plan file

  <INPUT>
          The recording

Options:
  -o, --output <OUTPUT>
          Where to write the audio. The subtitles take the same name

      --intensity <INTENSITY>
          0..1 -- how far the transform pushes
          
          [default: 1]

      --keep-accent
          Leave the speaker's accent and intonation intact

      --reseed-secs <RESEED_SECS>
          Seconds between modulation seed rolls; 0 keeps one stream
          
          [default: 2]

      --reseed-range <RESEED_RANGE>
          Draw each gap from a range instead, in milliseconds: `250,1800`.
          
          A fixed interval is a fixed thing to observe. With a range, the gap before every roll is drawn fresh from the modulation stream, so the ratchet has no period at all.
          
          Without this, the range is **drawn from the operating system's random source at launch**, so it is a property of this run rather than a number compiled into every copy of VeilVoice. Pass `--reseed-range fixed` to use `--reseed-secs` instead.
          
          A value that is not a usable range is **refused with the reason**, never adjusted to fit.

      --page
          Also write a self-contained HTML player beside the audio.
          
          The waveform, a circle per speaker that lights when they speak, and the subtitles. It reads the audio and the WebVTT track by name from the same directory, so move all of them or none.

      --width <WIDTH>
          Picture width in pixels
          
          [default: 1280]

      --height <HEIGHT>
          Picture height in pixels
          
          [default: 720]

      --padding <PADDING>
          Margin around everything, in pixels
          
          [default: 48]

      --background <BACKGROUND>
          A `#rrggbb` colour, or the path to an image file

      --black
          Plain black behind everything. Overrides `--background`

      --theme <THEME>
          Colour scheme, from the nine the website and the app offer.
          
          Defaults to Tokyo Night. An unknown name is refused, and the error lists every one it could have been.

      --one-voice
          Give every speaker the **same** voice.
          
          More private: the output then carries no trace of *which* speaker somebody was, so two recordings of the same group cannot be lined up by voice. The price is that only the names and the picture say who is speaking -- by ear alone, nobody can. It also has no speaker limit, because one voice cannot collide with itself.

  -h, --help
          Print help (see a summary with '-h')
